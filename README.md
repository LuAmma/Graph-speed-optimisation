# Graph speed optimisation
 This short script serves as example on how Graphs can be used to solve problems. It motivates the solution approach with the example of an EV on the highway with limited battery charge left.

## Running the Code
The easiest way to run the code is Binder. Open the following links (German):
* [Introduction](https://mybinder.org/v2/gh/LuAmma/Graph-speed-optimisation/introduction?urlpath=%2Fdoc%2Ftree%2FZustands_Graph.ipynb)

The libraries might need some time to download.
